一、快速开始
------------

1. 进入测试目录：
   cd /home/gwx/Workdir/riscv-rvv/benchmark

2. 验证环境（确保板卡在线）：
   ./verify.sh

3. 运行测试（需要5分钟）：
   ./run_test.sh

4. 查看结果：
   cat results/latest/report.txt


二、测试配置
------------

板卡IP：    192.168.3.63
计算线程：  8
并发对话：  4
测试时长：  300秒（5分钟）

测试任务：
  - Task 1: 技术解释（RVV详解）
  - Task 2: 代码生成（二叉搜索树）
  - Task 3: 数学计算（平均速度）
  - Task 4: 创意写作（AI自我意识）


三、记录的指标
--------------

每个任务会记录：
  ✓ 首字延迟 (TTFT)：首个token出现的时间，单位毫秒
  ✓ 平均 tok/s：每秒生成多少个token
  ✓ 最小/最大 tok/s：性能范围
  ✓ 总请求数：5分钟内完成多少次对话
  ✓ 总token数：总共生成了多少token


四、输出文件
------------

测试完成后，结果保存在 results/YYYYMMDD_HHMMSS/ 目录：

  config.txt          - 测试配置信息
  task_1.csv          - 任务1详细数据（每个请求）
  task_1.summary      - 任务1汇总
  task_2.csv / .summary
  task_3.csv / .summary
  task_4.csv / .summary
  report.txt          - 完整报告（推荐先看这个）
  report.json         - JSON格式（用于程序分析）


五、对比测试
------------

如果要对比优化前后的性能：

1. 先运行基线测试：
   ./run_test.sh
   mv results/latest results/baseline_cfs

2. 加载你的调度器（在板卡上）：
   ssh root@192.168.3.63
   sudo ./你的调度器 &
   exit

3. 再次运行测试：
   ./run_test.sh
   mv results/latest results/with_scheduler

4. 对比结果：
   ./compare.sh results/baseline_cfs results/with_scheduler


六、常见问题
------------

问题1：板卡连不上
  检查：ping 192.168.3.63
  解决：确保板卡通电且网络连接正常

问题2：SSH连接失败
  检查：sshpass -p bianbu ssh root@192.168.3.63 "echo test"
  解决：确认密码是否正确（在 config.sh 中配置）

问题3：测试中途失败
  查看日志：tail -f logs/benchmark_*.log
  解决：检查网络稳定性，确保板卡内存充足

问题4：性能异常低
  检查：ssh root@192.168.3.63 "top"
  解决：确保没有其他进程占用CPU


七、修改配置
------------

如果需要调整测试参数，编辑 config.sh：

  export TEST_DURATION=600      # 改为10分钟
  export LLM_THREADS=16         # 改为16线程
  export CONCURRENT_TASKS=8     # 改为8并发
